# Landing page — Nhà xuất bản Phụ nữ Việt Nam

Project riêng cho chat `019f7f29`, không phụ thuộc và không thay đổi project landing page cũ.

## Chạy project

Mở `index.html` trực tiếp hoặc dùng một static server trong thư mục này.

## Công nghệ

- HTML5, CSS3, JavaScript thuần
- Bootstrap 5.3.8 cho hệ lưới responsive và offcanvas
- Font Inter, fallback Segoe UI và sans-serif

## Nội dung và hình ảnh

- Nội dung: tài liệu Google Docs do người dùng cung cấp, phạm vi từ phần giới thiệu đến hết sách đạt giải thưởng.
- Ảnh hoạt động và logo: nguồn Nhà xuất bản Phụ nữ Việt Nam.
- Ảnh bìa sách được lưu cục bộ để tránh phụ thuộc hotlink. Cần xác nhận quyền sử dụng trước khi triển khai thương mại.
